# Sorpresa romántica 💙💗
Página estática (HTML/CSS/JS vanilla) para Kiara, de Zidane. Sin dependencias ni backend.

**Estructura:** `index.html` · `styles.css` · `app.js` · `config.js` (lo que editas) · `assets/fotos/` · `assets/musica/` · `GUIA_PERSONALIZACION.md`

**Inicio:** abre `index.html` en el navegador (o usa Live Server en VS Code).

**Probado:** sintaxis de JS validada con Node. No se hicieron pruebas en navegador real ni en celular; pruébalo tú siguiendo la guía.
